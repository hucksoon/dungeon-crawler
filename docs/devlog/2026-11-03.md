## 원거리 몬스터: 9칸 → 한 칸 (dc#150)

### 사용자 요청
- "원거리 몬스터들이 9칸 범위 공격을 하는데 거의 못피해. 한칸공격하는 것으로 변경해봐."

### 바꾼 것 (`monsters.js` RANGED.radius 1 → 0)
- 저주 구슬은 조준한 순간 내가 선 한 칸에만 떨어짐. 붉은 표시도 한 칸, 남은 턴(2, 3D 3)은 그대로 → 한 칸만 비키면 빗나감
- 3×3은 몬스터가 둘러싼 상태에서 2턴에 두 칸을 빠져나가야 해서 거의 못 피했음
- 한 방 세기(공격력 ×2)·주기(4턴)·거리(3~5칸)는 그대로

### 밸런스 (`tools/sim-v2.mjs`, 300판)
- 한 칸이라 피하기 쉬워짐: 피할 확률 50% → 80%로 보면 끝까지 일반 77% → 78%, 나이트메어 91% → 91%, 헬 46% → 64% (헬이 조금 쉬워짐)
- 사용자가 "피할 수 있게"를 먼저 원해서 세기는 그대로 두고 지켜봄

### 테스트
- `run149-e2e`: 규칙 radius 0, 방향키로 한 칸 비키면 안 맞음 (전에는 두 칸)
- 블로그 그림 `v11-ranged-one` (한 칸 표시 → 한 칸 비킴 → 빈 칸에 구슬). 어제 글의 `v10-ranged`(3×3)는 그대로 둠
