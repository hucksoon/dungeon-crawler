### 새벽 · 아이템과 몬스터 밸런스 개편 (#11)
플레이해 보고 느낀 문제를 고쳤어요.
- 강화하면 기본 능력치만 올랐는데, 이제 **+4, +6, +8, +10**마다 추가 능력치 한 줄도 올라요
- 세트 효과를 %로 오르는 좋은 능력치로 바꿨어요
- 주 능력치 개수: 일반·고급 1~2개, 레어 이상 3~4개
- 능력치마다 최소~최대 범위를 보여 주고, 최대치가 붙을 확률은 각각 20%
- 모든 수치가 최대인 아이템은 이름 앞에 **"고대"**가 붙어요
- 공격하면 데미지 숫자가 떠요. 치명타는 굵고 크게
- 층마다 몬스터가 더 강해지게 해서 포션을 쓸 일이 생기게 했어요. 포션은 최대 HP의 30%를 회복해요
- 몬스터 방어력 공식을 비율 방식으로 바꿨어요 (빼기 방식은 방어력이 너무 셌어요)
- 아이템 규칙 문서(items.md)를 만들었어요

### 오후 3시 · PHP 랭킹 서버 (#13)
- 처음엔 Cloudflare Workers로 만들었는데 가입이 막혀서, 이미 운영 중인 **우분투 Apache 서버**에 PHP 버전을 올렸어요
- 서버에 올리면서 하나씩 해결했어요
  - config.php 쉼표 빠짐 → 문법 오류
  - PHP SQLite·curl·mbstring 확장 설치
  - `.htaccess`가 동작하지 않아서 Apache 설정으로 `config.php`와 DB 폴더를 막았어요 (403 확인)
- 게임과 랭킹 페이지가 이 서버를 쓰도록 연결했어요

### 오후 4시 · 랭킹에서 장비 보기와 위조 검증 (#14)
- 랭킹에서 이름을 누르면 그 사람이 **최고 층을 세운 순간**의 능력치, 장비 6칸, 세트 효과, 최강 아이템이 보여요
- 서버가 아이템을 시드로 **직접 다시 만들어서** 확인해요. 게임이 보낸 능력치나 이름은 믿지 않아요
- 시드가 실제 게임에서 나올 수 있는 형식인지(몬스터, 포션 자리, 상점, 장비 상자)도 확인해요. 통과하지 못한 장비는 저장하지 않아요
- 배포 직후 이름이 안 눌렸는데, 브라우저가 예전 랭킹 화면을 기억하고 있었어요. 강력 새로고침으로 해결 ✅
