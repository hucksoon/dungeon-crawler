# 2026-10-19 (월) — v4 랭킹은 v4 장비로만

[← 개발 일기 목차](../devlog.md) · 이전: [2026-10-17 (토)](2026-10-17.md)

### 예전 장비를 낀 판은 v4 베타 랭킹 제외
- v3 베타 랭커가 v4 베타 랭킹에도 올라왔어요. v4 베타는 v4에서 내려간 층만 세지만 **장비 버전은 보지 않아서**, 예전 장비(150레벨이 넘는 것 포함)를 낀 채 1층부터 다시 내려가면 기록이 됐어요
- 규칙: **이번 판에서 예전(v3까지) 장비를 한 번이라도 끼면 그 판은 v4 베타 랭킹에 기록하지 않아요.** 가방에 보관하거나 거래소에 파는 건 괜찮아요
  - 끼는 순간 "이번 판은 v4 베타 랭킹에 기록되지 않아요" 안내가 나오고, 다시 빼도 그 판은 계속 제외예요. 인벤토리 능력치 창에도 보여요
  - 그런 판으로 150층을 깨도 게임은 완료되지만 랭킹의 "완료"는 아니에요
  - 예전 장비 없이 **1층부터 새로 시작하면** 다시 기록돼요
- 서버도 한 번 더 막아요: 장착 장비에 예전 아이템이 있으면 층 기록을 받지 않아요
- 이미 올라간 기록은 서버 명령 `admin.php`로 지워요 (`list`로 공개 ID 확인 → `remove <공개ID>`). v4 베타 기록만 지우고 v3 베타 기록은 그대로예요. 웹으로는 열리지 않아요
