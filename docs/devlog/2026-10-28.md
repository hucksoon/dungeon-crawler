- 정한 것 (질문에 대한 답): 3개 중 **1개 고르기**, 레벨은 **내 진행에 맞춰**
- 이어서: "추가로 적은 확률로 캐시도 1~3개 랜덤하게 받을 수 있게 해볼까?" → 로그인 계정만 10% 확률로 1~3개 (캐시는 Xsolla 계정에 들어가서 게스트·포털은 없음)

### 바꾼 것
- 게임 화면 오른쪽 위에 반짝이는 배너 "🎁 무료 선물 (광고)" (받을 수 있을 때만, 마을·던전 모두). 누르면 광고 → 선물 3개 창

  - 다음 선물은 광고를 본 때부터 3시간 뒤. 창이 열려 있는 동안 게임 키는 멈춤
- 선물 수준 (서버에 기록된 진행으로, 게임이 보내는 값은 믿지 않음)
  - 그 전: 일반 던전 세트 (최고 층에서 떨어지는 레벨)
  - 일반 던전 완료: 악몽의 세트 (나이트메어 최고 층 레벨)
  - 나이트메어 완료: 지옥의 세트 (헬 최고 층 레벨) + 헬에서 만난 네임드 보스의 유니크가 칸마다 반쯤 (그 보스 층 레벨)

- `index.html` 아래쪽에 "장비 상자 확률" 링크(`shop.html#odds`), 포털 버전은 상점이 없어서 숨김
