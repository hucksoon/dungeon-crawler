## 블로그 게임 이미지: 썸네일·스크린샷 보기와 내려받기 (dc#103)

### 사용자 요청
- (포털 등록용 썸네일·설명 문구를 만든 뒤) "내 블로그 안에도 해당 썸네일이랑 스크린샷을 보여주고 다운받을 수 있게 해줘. 필요하면 추가 페이지를 만들어줘."

### 그림 (포털 빌드 저장소)
- 포털 빌드 저장소의 `store/shots.mjs`가 포털 빌드를 띄워 그림을 만듦
  - 썸네일 4장: 가로 1920×1080, 세로 800×1200, 정사각형 800×800·1200×1200. 헬 10층 넓은 방에서 화염의 세트를 입은 플레이어가 몬스터 8마리에게 화염구를 터뜨리는 순간을 4배로 찍고 로고를 얹음 (피해 숫자는 뺌)
  - 스크린샷 5장 (1280×720, 영어): 마을, 헬 전투, 던전, 인벤토리, 도감
- 같은 곳에 포털 설명 문구(영어·한국어·일본어: 한 줄 소개, 짧은·긴 설명, 조작법, 태그)

### 블로그
- 새 페이지 `blog/media.html` "게임 이미지": 썸네일·스크린샷을 작은 미리보기로 보여 주고, 누르면 원래 크기, 장마다 내려받기 버튼, 전체 zip 내려받기 (9장, 약 5.4 MB)
- 블로그 첫 화면 위쪽과 모든 페이지 아래에 "게임 이미지" 링크
- `tools/media-sync.mjs`: 포털 빌드 저장소의 그림을 `blog/media/`에 `dungeon-crawler-*.png`로 복사하고, 미리보기(폭 480 JPG, 장마다 20~50 KB), 크기·용량 목록(`media.json`), zip을 만듦. 그림을 다시 만들면 이걸 돌리고 `tools/blog-build.mjs`
- `tools/blog-build.mjs`가 목록으로 페이지를 만들고, 목록에 있는 파일이 없으면 멈춤
- 블로그 그림 도구에 이 페이지 장면 추가 (`media-page`)

## 발소리·착지 소리, 포털에서 업데이트 안내 숨김 (dc#104)

### 사용자 요청
- "포털에서 업데이트 안내 뜨는 거 고쳐줘."
- "추가로 현재 던전이나 로비에서 움직일 때 사운드가 있나? 없으면 동일하게 추가해서 적용해줘. 마리오 같은 사운드가 있으면 해."

### 바꾼 것
- 포털 모드에서는 위쪽 업데이트 안내 줄(원본 사이트의 바뀐 기록)을 띄우지 않음. 원본 사이트는 그대로
- 그전에는 걸을 때 소리가 없었음 (마을 점프 소리만). 새 효과음 (`sound.js`):
  - `step`: 마리오 같은 8비트 '톡톡'. 짧게 떨어지는 네모파와 작은 흙 소리, 왼발·오른발 높이를 조금 다르게. 마을은 밝게, 던전은 낮고 둔하게
  - `land`: 점프하고 내려설 때 '툭'
- 던전: 빈 칸으로 한 칸 걸을 때마다 발소리 (몬스터를 때릴 때는 없음, 칸 눌러 자동 걷기도 한 칸마다). 점프(Space + 방향)도 이제 뛰는 소리와 착지 소리
- 마을·점프 던전(운영자): 땅에서 한 칸 걸을 때마다 발소리 (뛰는 중·사다리에서는 쉼), 착지하면 '툭'
- 소리 설정에 "발소리" 켜기·끄기 (효과음과 따로, 이 기기에 저장. 효과음을 끄면 같이 꺼짐). 영어·일본어 번역

### 테스트
- `sound-e2e` 37/37 (새 8개): 몬스터를 때릴 때 발소리 없음, 던전 한 칸 걸으면 발소리, 던전 점프 → 뛰는 소리 다음 착지 소리, 마을 착지 소리, 마을 0.7초 걷기에 발소리 3~8번, 발소리 기본 켜짐, 끄면 발소리만 안 나고 다른 효과음은 남, 효과음을 끄면 발소리 칸도 꺼짐
- `portal-e2e` 20/20 (새 1개): 다시 들어온 포털 사용자에게 업데이트 안내 줄이 없음 (고치기 전 코드로 돌리면 실패하는 것도 확인)
