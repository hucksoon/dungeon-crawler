### 사용자 요청

### 운영자 장비 지우기 (`index.html` Inv.staffWipe, `#inv-staff-wipe`)
- 인벤토리 아래 운영자에게만 보이는 버튼 "🧹 운영자: 장비·강화석 모두 지우기 (테스트)" → 확인 창 → 가방·낀 장비·강화석(일반·악몽·지옥)을 모두 비움
- 보석·룬(서버 보관)과 보상 표시는 그대로라 보상을 다시 받지 않음. 저장은 2초 뒤 서버에 올라가 다른 기기에도 같음
- 서버를 직접 고치지 않고 게임 안에서 하니, 테스트할 때마다 다시 눌러서 처음부터 시작할 수 있음

### 마을 다시 놓기 · 시간 상점 없앰 (`jump.js` TOWN, `jump.js?v=102`)
- 왼쪽부터: 거래소(점검 중)·우편함 → 던전 입구(1층·이어하기) → **가운데 웨이포인트** → 나이트메어 → 헬 → 골드 던전
- 던전은 가는 순서대로(일반 → 나이트메어 → 헬), 따로 도는 골드 던전은 오른쪽 끝. 웨이포인트는 그대로 마을 정가운데
- 시간 상점(매시간 바뀌는 골드 장비 상점)은 건물과 문을 없앰: 장비는 줍는 즉시 자동 장비·강화라 살 이유가 없고, 골드는 축복 다시 뽑기에 씀. 이미 산 아이템은 그대로
- 할로윈 잭오랜턴 자리도 새 건물 사이로 옮김

## 판은 언제나 레벨 1·1층부터, 속성 스킬 축복, 큰 던전 입구 (dc#142)

### 사용자 요청
- "레벨도 매 게임마다 초기화가 되야하잖아. 지금 적용되어있는거지?" → 아니었음 (dc#95: 쓰러지면 경험치 10%만 잃고 레벨은 이어 감, 웨이포인트로 중간부터 시작 가능)
- "웨이포인트도 우선 숨김처리해주고 항상 1레벨 1층부터 시작하게 해줘. 그리고 능력치가 오르는 축복도 좋지만 속성 공격 축복을 많이 보여지게해서 재미를 늘려줘."
- "구멍은 헬50층을 클리어했을때만 추가로 플레이할 수 있게 수정해줘."
- "마을에는 거래소·우편함·던전 입구만 남겨요. 다만 일반 던전 건물을 좀 더 화려하게 바꿔주자."
- 속성 축복: "화염구(화상)·얼음 폭발(둔화)·연쇄 번개를 처음 고르면 스킬이 생기고, 같은 걸 또 고르면 피해·범위·횟수가 커져요. 매 층 후보 3개 중 1개 이상은 속성 축복이 나오는 부분은 피하자. 하지만 나올 확율은 커지는 방향으로. 사용자가 헬던전까지 깰 경우 3개 이상 속성을 모두 마스터할 수는 없게."

### 판 규칙 (`index.html`)
- 새 판은 언제나 레벨 1·골드 0·일반 1층 (`FRESH`): 쓰러진 뒤 "로비에서 새로 시작"(경험치 10% 잃기 없앰)과, 진행 중인 판이 있을 때 마을 1층 문(확인 창 "레벨 1·골드 0으로 시작해요")
- 웨이포인트 없음: 던전 ◎이 안 생기고 계단도 막지 않음, 튜토리얼 ⑤ 뺌. 나이트메어·헬은 같은 판에서 앞 던전 50층을 깨고 이어가기로만
- 끝이 없는 구멍: 헬 50층을 깨면 "끝이 없는 구멍 1층으로 바로 이어갈까요?" → 레벨·축복·유물 그대로. 마을에서는 못 들어감 (`enterAbyss({ cont })`)
- 이어가기를 취소하면 마을에 남고, 파란 포탈로 돌아가 그 던전 50층 보스를 다시 쓰러뜨리면 또 물어봄

### 속성 스킬 축복 (`blessings.js` ELEM, `index.html` stats·castSkills)
