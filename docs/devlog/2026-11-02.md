### 사용자 요청

### 운영자 장비 지우기 (`index.html` Inv.staffWipe, `#inv-staff-wipe`)
- 인벤토리 아래 운영자에게만 보이는 버튼 "🧹 운영자: 장비·강화석 모두 지우기 (테스트)" → 확인 창 → 가방·낀 장비·강화석(일반·악몽·지옥)을 모두 비움
- 보석·룬(서버 보관)과 보상 표시는 그대로라 보상을 다시 받지 않음. 저장은 2초 뒤 서버에 올라가 다른 기기에도 같음
- 서버를 직접 고치지 않고 게임 안에서 하니, 테스트할 때마다 다시 눌러서 처음부터 시작할 수 있음

### 마을 다시 놓기 · 시간 상점 없앰 (`jump.js` TOWN, `jump.js?v=102`)
- 왼쪽부터: 거래소(점검 중)·우편함 → 던전 입구(1층·이어하기) → **가운데 웨이포인트** → 나이트메어 → 헬 → 골드 던전
- 던전은 가는 순서대로(일반 → 나이트메어 → 헬), 따로 도는 골드 던전은 오른쪽 끝. 웨이포인트는 그대로 마을 정가운데
- 시간 상점(매시간 바뀌는 골드 장비 상점)은 건물과 문을 없앰: 장비는 줍는 즉시 자동 장비·강화라 살 이유가 없고, 골드는 축복 다시 뽑기에 씀. 이미 산 아이템은 그대로
- 할로윈 잭오랜턴 자리도 새 건물 사이로 옮김
