## 운영자 입구, 장신구 수치·강화, 운영자 아이템 받기 (dc#49)

### 사용자 요청
1. 운영자 입구(포탈)가 헬 10층으로만 가는데 어떤 기능이었지?
2. 장신구는 고정 % 능력치라 강화해도 의미가 없어 보임
3. 운영자가 장비를 테스트하려면 매번 파밍해야 함 → 유니크나 세트 장비를 바로 얻는 버튼

### 운영자 입구
- 원래 기능: **마지막으로 쓰러진 곳**(던전·층)으로 바로 들어감. 마지막으로 헬 10층에서 쓰러져서 계속 헬 10층으로 감
- 사용자 결정: 포탈을 탄 층을 새로 만들어 다시 돌 수 있게 → **마지막으로 쓰러지거나 포탈(P)을 탄 층**을 새 지도·새 몬스터로 만들어 들어감 (같은 층을 반복해서 테스트)

### 장신구 주 능력치: % → 수치 (규칙 r8)
- 사용자 결정: 공격력·방어력·최대 HP를 %가 아니라 그에 맞먹는 범위로
- r8 장신구 주 능력치 = **공격력·방어력·최대 HP 3줄**. 범위는 다른 장비 주 능력치 범위(레벨) × 레전더리 1.75 × 능력치 배율 × 등급 배율 (일반 던전은 × 0.55), 악몽의 힘 ×3·지옥의 힘 ×5, **강화하면 다른 장비처럼 오름 (+10이면 2배)**
- 세기 맞추기: 단계별 추천 장비(줄 품질 95% +10)에서 레전더리 장신구 25%와 같은 수치를 계산 → 나이트메어·헬 모두 공격 0.53~0.55·방어 2.1·HP 2.3~2.5배로 고르게 맞음
  - 처음엔 +0에서 25%와 같게 했더니 +10 강화(2배)면 헬 50층이 모든 장비 품질에서 0% → **+10에서 25%와 같게** (배율 절반: 공격 0.275·방어 1.05·HP 1.2)
  - 시뮬레이션 (헬 50층, 장비 95% +10, 몰려옴 / 염라대왕): 장신구 +0 100% / 98% · +5 55% / 65% · **+10 20% / 19%** (예전 % 장신구 18% / 23%와 같음) · +12 11% / 12%
  - 나이트메어 50층 고대 + 장신구 +10: 몰려옴 16% (그대로), 일반 75층 장비·장신구 +8: 1%
- 예전(r7) 장신구는 그대로 "% 한 줄" (강화로 안 오름). 레전더리 장신구의 고대는 주 능력치 3줄이 모두 최대치일 확률이 아주 낮아 거의 드롭 고대 굴림 3%만큼
- 서버: 생성 규칙 r8, 유니크 r8 허용. JS·PHP 아이템 생성 같음 (r8 장신구·유니크 장신구 포함)

### 운영자 아이템 받기
- 인벤토리 가방 아래 **🎁 운영자: 아이템 받기** 버튼 (운영자 기기만)
  - 유니크 장비 10개·유니크 장신구 5개 (하나씩 또는 전부), 세트 6개(부위 전부), 레전더리 장신구 3개(목걸이·반지 2)
  - 세트·장신구는 헬(지옥의) / 나이트메어(악몽의) 고르기, "고대로 받기" 체크하면 고대로
  - 실제 규칙으로 만든 아이템 (유니크는 네임드 드롭과 같은 시드 모양·굴림, 세트·장신구는 그 단계 50층 보스 드롭)
- 테스트: 운영자 e2e 52개 (아이템 받기·포탈 탄 층으로 운영자 입구), 장신구 e2e 34개 (r8 범위·강화·r7 그대로·서버)

### 서버 확인
- dc#49 (PR #46): 파일 7개 모두 일치, `api.php`·`rules.php` 문법 오류 없음, r8 장신구 규칙·r8 허용 (검색 결과 2·1·2, 저장소와 같음), v4 베타 랭킹 정상 (7명, 이메일 가림), 헬 랭킹 응답 정상 (0명)

## 최고 조합 페이지, 추천 탭 줄이기 (dc#50)

### 사용자 요청
- 헬 밸런스 다시 (숫자 장신구 r8 뒤): 95% 헬 50층 19% / 24%로 목표대로, 이무기 90% 38% → 15%로 튀지 않음, 시험의 세트 6·천하무적이 0% / 0%로 세짐 (세트 % 효과가 장신구 수치에도 곱해져서) — 고칠 것 없음
- 유니크 없이 (세트 + 룬워드) / 유니크 포함 최고 조합 시뮬레이션 → 추천 장비가 길어지니 게임에는 가장 강한 유니크만, 두 결과는 **외부 창 페이지**로. 주 능력치·추가 능력치는 뭐가 좋은지, 안 쓰이는 룬워드·유니크는 뭔지

### 최고 조합 (헬 50층, 95% +10, 장신구 +10, 부위를 하나씩 바꿔 가며 찾고 500번 확인)
- 유니크 없이 1위: **필살일격(장검) + 마음가짐(방패) + 천하무적 + 뇌전의 세트 4** — 0% / 0% (19턴 / 19턴). 2위 폭풍전야 + 마음가짐 + 천하무적 + 화염의 세트 4 (13 / 24턴, 폭풍전야는 시뮬레이션이 조금 좋게 봄), 3위 태산(단검) + 화염의 세트 5
- 유니크 포함 1위: **여우구슬 지팡이 + 레전더리 보조 단검 + 화염의 세트 5** — 0% / 0% (10턴 / 13턴). 지팡이 + 사자의 낫 + 시험의 세트 5 (13 / 9턴), 지팡이 + 화염 4 + 명부의 사슬 (11 / 11턴), 유니크 7 (14 / 11턴)
  - 유니크를 다 모으기보다 강한 유니크(특히 여우구슬 지팡이) + 세트를 섞는 게 가장 빠름
- 줄 고르기 (1위 조합에서 한 줄씩 바꿔 봄, 품질 95%는 모두 0%라 75%에서 차이 확인): 세트는 ★ 방어력·최대 HP(팔 치명타·공격력%, 바지 방어력%) ◆ 치명타·치명타 피해·공격력% + 최대 HP(장화 방어력). 흡혈이 모자란 1위(14%)는 투구에 흡혈, 스킬 조합은 속성 피해 줄(머리 얼음 피해 = 노바, 가슴 불 피해 = 파이어볼). 장신구 저항은 속성 하나씩 + 모든 속성
- 안 쓰이는 것 (그 아이템을 꼭 낄 때 가장 좋은 조합): 룬워드 나무·치유·도원결의·기억·카리스마·몰래·선견지명 (46~64턴, 1위 38턴), 유니크 여의주 검(34턴)·송곳니(38턴)·업경대(47턴, 1위 23턴), 유니크 장신구 쇠이빨 목걸이·여의 반지 (한 속성 저항 최대치뿐)
