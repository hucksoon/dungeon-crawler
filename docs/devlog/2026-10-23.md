## 운영자 입구, 장신구 수치·강화, 운영자 아이템 받기 (dc#49)

### 사용자 요청
1. 운영자 입구(포탈)가 헬 10층으로만 가는데 어떤 기능이었지?
2. 장신구는 고정 % 능력치라 강화해도 의미가 없어 보임
3. 운영자가 장비를 테스트하려면 매번 파밍해야 함 → 유니크나 세트 장비를 바로 얻는 버튼

### 운영자 입구
- 원래 기능: **마지막으로 쓰러진 곳**(던전·층)으로 바로 들어감. 마지막으로 헬 10층에서 쓰러져서 계속 헬 10층으로 감
- 사용자 결정: 포탈을 탄 층을 새로 만들어 다시 돌 수 있게 → **마지막으로 쓰러지거나 포탈(P)을 탄 층**을 새 지도·새 몬스터로 만들어 들어감 (같은 층을 반복해서 테스트)

### 장신구 주 능력치: % → 수치 (규칙 r8)
- 사용자 결정: 공격력·방어력·최대 HP를 %가 아니라 그에 맞먹는 범위로
- r8 장신구 주 능력치 = **공격력·방어력·최대 HP 3줄**. 범위는 다른 장비 주 능력치 범위(레벨) × 레전더리 1.75 × 능력치 배율 × 등급 배율 (일반 던전은 × 0.55), 악몽의 힘 ×3·지옥의 힘 ×5, **강화하면 다른 장비처럼 오름 (+10이면 2배)**
- 세기 맞추기: 단계별 추천 장비(줄 품질 95% +10)에서 레전더리 장신구 25%와 같은 수치를 계산 → 나이트메어·헬 모두 공격 0.53~0.55·방어 2.1·HP 2.3~2.5배로 고르게 맞음
  - 처음엔 +0에서 25%와 같게 했더니 +10 강화(2배)면 헬 50층이 모든 장비 품질에서 0% → **+10에서 25%와 같게** (배율 절반: 공격 0.275·방어 1.05·HP 1.2)
  - 시뮬레이션 (헬 50층, 장비 95% +10, 몰려옴 / 염라대왕): 장신구 +0 100% / 98% · +5 55% / 65% · **+10 20% / 19%** (예전 % 장신구 18% / 23%와 같음) · +12 11% / 12%
  - 나이트메어 50층 고대 + 장신구 +10: 몰려옴 16% (그대로), 일반 75층 장비·장신구 +8: 1%
- 예전(r7) 장신구는 그대로 "% 한 줄" (강화로 안 오름). 레전더리 장신구의 고대는 주 능력치 3줄이 모두 최대치일 확률이 아주 낮아 거의 드롭 고대 굴림 3%만큼
- 서버: 생성 규칙 r8, 유니크 r8 허용. JS·PHP 아이템 생성 같음 (r8 장신구·유니크 장신구 포함)

### 운영자 아이템 받기

## 아이템 발견, 룬워드 남는 홈, 나무 상향 (dc#51)

### 사용자 요청
- 안 쓰이는 룬워드·유니크를 어떻게 쓰게 할까 → 파밍용(유니크·레전더리·세트가 더 나오는) 옵션
- 유니크 확률과 아이템 발견을 나눌 필요가 있을까? 추천에도 없고 발견%도 없으면 안 쓸 것 → **하나로 합침 (아이템 발견 %)**
- 무기·보조무기 7종(룬워드 포함)을 얻는 난이도는? "홈 4개 장검·방패 커먼이 1.5만~3만 마리에 하나"는 왜 이렇게 어려운지?
  - 커먼은 추가 능력치 1줄이라 그 줄이 홈일 확률이 약 6%, 장검 홈은 4~6개라 딱 4개가 40% → 같은 종류 커먼 중 약 2.4%. 몬스터 드롭 → 커먼 → 장검까지 곱하면 1.5만~3만 마리
- 결정: **룬워드는 홈이 룬보다 많아도 됨** (처음엔 남는 홈에 보석을 넣게 했다가 → 사용자 의견: 룬워드를 완성하면 남는 홈은 없어지게), 송곳니는 헬 초반 추천 + 아이템 발견, 나무는 공격력%·치명타 피해 상향. 장검 + 방패 룬워드(선견지명·카리스마·도원결의)와 여의주 검·업경대는 다음에

### 시뮬레이션
- 파밍 수입 (헬 30층 처치 1번, 실제 드롭 규칙 3만 번): 발견 0% 레전더리+세트 0.74%·판매 골드 109 → 50% 1.23% (×1.67)·161 → **100% 1.73% (×2.33)·212**. 헬 10·50층도 ×2.1~2.2. 원하는 유니크 하나에 네임드 13.3번 → 10번
  - 파밍 장비(기억·몰래 + 쇠이빨·여의 반지 2)는 최고 조합보다 느려서 시간당 약 1.3~1.6배. 무기 자리까지 파밍 장비로 바꾸면 너무 느려서 손해
- 헬 초반 무기·보조무기 (그 층 레전더리 품질 85% +10, 몰려옴 / 네임드, 10·20·30층): **송곳니 + 보조 단검 0·2·0%** (몰려옴 0%), 나무(상향) + 보조 단검 5·11·12% (30층 몰려옴 22%), 레전더리 단검 2 14·17·34%, 카리스마 + 레전더리 방패 93·28·100% (장검 + 방패는 느려서 네임드 패턴을 오래 맞음)
- 안 쓰이는 룬워드 만드는 비용 (50층 보스 판 수): 나무 약 5판, 선견지명 22, 도원결의 24, 카리스마 41

### 바꾼 것 (규칙 r8 그대로, 서버 검증 추가)
- **아이템 발견 %** (최대 100): 처치마다 10% × 발견% 확률로 보너스 아이템 하나 (보물 표: 레어 이상, 시드 …|층|f처치 순번), 네임드 유니크·유니크 장신구 확률 × (1 + 발견% / 300) → 100%면 15 → 20%, 10 → 13.3%
  - 붙는 곳: 룬워드 치유 +20·기억 +25·몰래 +25, 유니크 송곳니 +20, 쇠이빨 목걸이 +20, 여의 반지 +15 (두 개면 +30). 기억 + 몰래 + 쇠이빨 + 여의 반지 2 = 100%
  - 서버: |f 시드는 r8 이상·보물 표·드롭 굴림이 최대 발견(10%) 안·층과 레벨이 맞아야 받음. r8 유니크는 최대 발견의 확률(20%·13.3%)까지 받음
- **룬워드 남는 홈**: 홈 개수 ≥ 룬 수면 재료. 앞 홈부터 정해진 순서의 룬을 모두 넣으면 완성되고 **남는 홈은 없어짐** (예: 홈 6개 장검 → 홈 4개 필살일격, 넣기 전 확인 창에 "남는 홈 2개는 없어져요"). 홈 초기화하면 원래대로. 룬워드 재료 커먼 0.65% → 0.9%
- **나무**: 불 피해 +15%·불 저항 +20%·흡혈 +4%에 **공격력 +30%·치명타 피해 +30%**
- 최고 조합 페이지에 **3. 헬 초반 · 4. 파밍** 탭, 잘 안 쓰이는 아이템에서 나무·송곳니 빼고 파밍용 표시. 게임 헬 추천 탭에 헬 초반(송곳니)·파밍(아이템 발견 N / 100%) 줄, 능력치 화면에 🔍 아이템 발견 줄
- 테스트: 아이템 발견 e2e 40개 (규칙·보너스 드롭·유니크 확률·룬워드 남는 홈·JS/PHP 같음·서버 |f 시드 받기/거절·추천 탭·최고 조합 페이지)

## 장검·방패 룬워드를 파밍용으로 (dc#52)

### 사용자 요청
- 장검 + 방패 룬워드(선견지명·카리스마·도원결의)는 느려서 헬 초반 네임드에게 93~100% → 차라리 **초반에 아이템 발견 100%로 쓰는 파밍용 무기**로. 공격 스킬을 붙이고, 파밍에 좋고, 흡혈도 되게

### 바꾼 것
- 세 룬워드에 **아이템 발견 +25%**씩 → 기억(투구) + 몰래(갑옷) + 장검 룬워드 + 도원결의(방패) = **100%** (유니크 없이 룬워드 4개)
- 공격 스킬 (모두 흡혈 됨):
  - **선견지명 · 회전 베기**: 2턴마다 주변 8칸 적 모두에게 공격력의 50% (물리, 치명타 됨). 공격력 +20% 추가, 보호막 10%는 빠짐
  - **카리스마 · 처치 폭발**: 쓰러뜨린 몬스터가 터져 주변 8칸 적에게 그 몬스터 최대 HP의 20% (방어력 무시, 폭발로 쓰러지면 이어서 터짐, 구미호 분신은 안 터짐)
  - **도원결의 · 반격**: 방패로 막으면 그 몬스터에게 공격력의 60%
- 서버 rules.php 같은 수치 (아이템 생성은 그대로, 룬워드 능력치만)
- 최고 조합 페이지 4. 파밍: **초반 파밍(룬워드 4개)** / 후반 파밍(유니크 장신구) 두 조합과 층별 결과, 잘 안 쓰이는 아이템은 치유만 남음. 게임 헬 추천 탭·배너도

### 시뮬레이션 (헬 10·20·30층, 그 층 레전더리 품질 85% +10 + 레전더리 장신구 +10)

## 저항 감소 나이트메어 −40·헬 −70, 몬스터 방어력, 운영자 룬워드 베이스 (dc#54)

### 사용자 요청
- 도감을 보니 몬스터 방어력이 너무 낮음, 의도한 것인가? → 아니었음: 방어력은 층마다 +0.4뿐이고 나이트메어·헬은 HP·공격력만 배율이라 **나이트메어부터 40 근처로 멈춰 있었음** (헬 50층 플레이어 공격력 약 10,000의 0.4%)

  - 시뮬레이션: 추천 장비의 저항 합이 이미 나이트메어 111%·헬 122~158%라, 요청대로 −10·−30이면 거의 다 75%에 닿고 헬은 오히려 쉬워짐 (65% → 75%) → 더 크게

- 운영자: 룬워드 베이스(홈이 달린 커먼)를 일반·나이트메어·헬로 받는 버튼

### 바꾼 것
- **속성 저항**: 그 던전의 내 저항 = min(최대치, 장비 저항 합 − 감소). 나이트메어 −40 (악몽의 골드 던전도), 헬 −70 (monsters.js ELEMENTS.zonePenalty). 저항이 음수면 그만큼 더 아픔
  - 능력치 화면에 "장비 합 115/115/115% − 40 (나이트메어)", 들어갈 때 안내, 추천 탭 "75% (장비 합 −40: 115% 모으기)"

  - 시뮬레이션 (줄 품질 95% +10): 장비 합 115% → 나이트메어 75% (몰려옴 26%), 헬 148% → 75% (16% / 25%). 전 추천이면 89% → 49% (42%), 헬 122% → 52% (26% / 38%)
- **몬스터 방어력**: 나이트메어 = 일반 75층 방어력 × 1.8 × 공격력 층 배율 (1층 약 70 · 50층 약 480), 헬 = 그 위에 헬 공격력 층 배율 (50층 약 1,060) → 플레이어 공격력의 약 10%. 일반 던전은 그대로
  - 방어력만 올리면 피해가 약 4% 줄고, 한 번에 덜 때리는 만큼 흡혈도 덜 들어와서 쓰러질 확률이 4~10% 올라감 → 나이트메어 몬스터 **HP × 0.96 · 공격력 × 0.98** (헬도 이걸 바탕으로 만들어서 같이)
  - 맞춤 (방어력만 바꾼 비교, 1000번): 나이트메어 50층 추천 27% → 26%, 헬 50층 레전더리 15% → 13%, 턴 그대로. HP ×0.96만이면 37% / 21%, 공격력도 ×0.96이면 19% / 7%
  - 약한 타격(보조 손 60%·광란·회전 베기 50%)일수록 방어력 영향이 크고, 스킬·속성 피해는 방어력 무시
