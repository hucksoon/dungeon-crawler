### 살펴본 것
- 엑솔라 디스코드 봇 (developers.xsolla.com/bot-in-discord): 디스코드 개발자 포털에서 앱을 만들고 봇 토큰을 Publisher Account → Storefront → Xsolla Bot in Discord에 넣음 (프로젝트당 1개). 플레이어는 `/shop`에서 플레이어 ID를 입력하고, 엑솔라가 그 ID를 `user_validation` 웹훅으로 물어봄 → 결제되면 `order_paid`
- 디스코드 개발자 포털: Interactions Endpoint URL은 비워 둠 (넣으면 명령이 그 주소로만 가서 엑솔라 봇이 받지 못함). Linked Roles도 비움. Privacy Policy URL은 `privacy.html`, Terms of Service URL은 없었음
- 아직 정할 것: 봇에서 팔 상품(스킬 스킨은 캐시 가격뿐), 게임 안 "내 플레이어 ID" 표시, 봇에서 산 아이템이 엑솔라 인벤토리에 들어가는지와 봇 웹훅 서명 (테스트 결제로 확인)

### 바꾼 것
- **이용약관** (새 `terms.html`): 한국어 · 영어 · 일본어 (버튼, `?lang=`, 게임에서 고른 언어 → 브라우저 언어 순). 계정, 캐시와 유료 아이템(현금 가치 없음, 결제는 Xsolla가 판매자), 청약철회와 환불(쓰지 않은 캐시는 7일 안, 쓴 캐시·바로 지급되는 스킨·부활권은 법이 허용하는 범위에서 제한, 미성년자 취소), 광고 보상, 금지 행동, 제재, 게임 변경과 종료(30일 전 알림), 책임, 개인정보, 약관 변경(7일 · 불리하면 30일 전), 준거법(대한민국), 문의처
- 게임 아래 링크: "장비 상자 확률"(상점에서 확률 표가 빠짐) → "이용약관". 상점 아래에도 이용약관 링크. 포털 빌드는 개인정보처리방침처럼 숨김
- 디스코드 봇 아이콘(1024×1024, 동그랗게 잘려도 문장이 다 보이게)과 배너(1360×480, 로고 · 몬스터 · 푸른 번개 오라)는 저장소에 넣지 않고 따로 전달

## 내 플레이어 ID 표시와 복사 버튼 (dc#174)

### 사용자 요청
- (디스코드 봇 설정 중: Bot token 경고, Admin access 역할 → 우리 디스코드 앱 토큰으로 바꾸고, 관리자 권한은 운영자 역할 하나만)
- 게임 안에 내 플레이어 ID 표시랑 복사 버튼 만들어줘

### 바꾼 것
- 계정 줄에 "🆔 플레이어 ID" 버튼 (로그인했을 때만, 포털 빌드는 숨김). 누르면 창에 내 플레이어 ID와 복사 버튼, "디스코드의 던전 크롤러 상점(/shop)에서 이 ID를 넣으면 이 계정으로 아이템을 받아요" 안내
- 플레이어 ID = Xsolla Login 사용자 ID (로그인 토큰의 `sub`). 게임 서버의 `user_validation` 웹훅이 확인하는 값과 같음. 본인 화면에만 보이고, 따로 보내거나 저장하지 않음
- 복사: 클립보드에 넣고 "복사했어요!" (클립보드를 못 쓰면 글자를 골라 두고 직접 복사 안내). Esc · 바깥을 누르면 닫힘
- 한국어 · 영어 · 일본어

### 테스트
- 새 `pid-e2e` (8개): 게스트는 버튼 없음, 로그인하면 버튼 → 창에 ID와 /shop 안내, 복사하면 클립보드에 그 ID, Esc로 닫힘, ID를 새로 저장하지 않음, 영어
- 블로그 그림 `v30-pid` · `v30-pidbar`
