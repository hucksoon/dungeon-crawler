## 디스코드 상점 봇 로그인 확인 (dc#175)

### 사용자 요청
- 디스코드 봇에 로그인하려고 하니 "External authorization service is unavailable" 에러가 나
- (웹훅 문서) https://developers.xsolla.com/webhooks/user-validation/user-validation-in-webshop

### 살펴본 것
- 봇의 "User authentication webhook"에 결제 웹훅 주소(`webhook.php`)를 넣었는데, 봇은 웹샵의 사용자 확인 형식으로 보냄: `{"user": {"id", "country"}, "settings": {...}}`, 성공이면 **200 + `{"user": {"id"}}`**
- `webhook.php`는 `notification_type`과 웹훅 비밀 키 서명이 없으면 400으로 거절하고, 성공도 204(본문 없음) → 봇이 "확인 서비스를 쓸 수 없음"으로 봄

### 바꾼 것
- 새 `ranking-php/bot_auth.php`: 플레이어 ID(Xsolla Login 사용자 ID, UUID)가 게임에 로그인한 적 있는 계정이면 200 `{"user": {"id"}}`, 모르면 404 `INVALID_USER`, 형식 오류 400, GET 405, 다른 프로젝트 400. 붙여 넣을 때 생긴 공백·대문자는 정리
- 서명 방식이 문서에 없어서 서명은 확인만 하고 로그에 상태를 남김 (`bot_auth_require_sig`로 필수, `bot_auth_ips`로 보내는 IP 제한 가능). 돌려주는 것은 그 ID가 게임 계정인지뿐 (이메일 등 없음). ID는 저장하지 않고 HMAC으로만 찾음, 로그에도 남기지 않음
- 결제 웹훅(`webhook.php`)은 그대로 서명 필수
- 서버 설명서(ranking-php/README.md)에 설정 방법

### 테스트
- 새 `botauth-api-test` (13개): GET 405, 모르는 ID 404, 게임 로그인 뒤 200 `{user:{id}}`(서명 없이·있어도), 공백·대문자, 다른 본문 모양, UUID 아님 404, ID 없음·JSON 오류 400, 다른 프로젝트 400, 서명 필수 설정, IP 제한, 로그에 ID 없음

### 살펴본 것
- 오늘 `webhook.php`에 온 사용자 확인은 19:06 · 19:07(UTC) 두 건뿐. 그 뒤 디스코드에서 시도할 때는 어느 주소에도 요청이 없음

### 바꾼 것
- `webhook.php` 사용자 확인: 결과(ok/unknown)와 요청 모양(항목 이름만, 예: `notification_type,settings{merchant_id,project_id},user{id}`), ID 종류(uuid/test/other)를 로그에 남김. ID · 이메일 · IP 값은 남기지 않음
- 붙여 넣은 공백 정리, Xsolla Login 사용자 ID(UUID)는 소문자로 맞춰 찾음 (bot_auth.php와 같게)
- 서버 설명서에 확인 명령
