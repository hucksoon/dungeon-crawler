## 할로윈 첫날 오전 10시 전 표시, 사탕은 눌러야 받기 (dc#136)

### 사용자 요청
- "할로윈 이벤트 시작했는데 게임 로비에서 클릭하자마자 이벤트 재화가 받아지는 것 같아. 자동으로 받게 하지말고 상점에서 클릭해서 받게 수정해줘." (상점 이벤트 칸 캡처: 오늘의 무료 사탕 버튼이 "The daily gift has ended", 캐시 바꾸기 칸에 사탕 0개인데 1)

### 무슨 일이었나
- 10/31 0시(한국 시간)에 테마(마을·몬스터·로고)는 켜졌지만, 받기의 하루(`event_xday`)는 Xsolla 구매 제한처럼 오전 10시에 바뀌어서 아직 10/30 → 서버 `event_status`의 `open: false`
- 상점이 `open: false`를 모두 "받기 기간이 끝났어요"로 보여 줘서, 이미 받은(또는 끝난) 것처럼 보였음. 실제로 받은 것은 없음 (사탕 0개, `event_claims` 기록 없음)
- 마을 배너는 상점으로 가기만 함 (받지 않음). 다만 상점은 열 때, Xsolla에 오늘 주문은 됐는데 서버가 아직 재화로 안 바꾼 것(받는 도중 창을 닫음)을 저절로 꺼냈음 (dc#131)

### 바꾼 것
- `shop.html`
  - 첫날 0시~10시(`ev.day`가 이벤트 시작 전): 버튼 "오전 10시부터 받을 수 있어요"(영어 "Available from 10:00 (KST)", 일본어 "午前10時から受け取れます"). 기간이 끝난 뒤에만 "받기 기간이 끝났어요"
  - 상점을 열 때 저절로 꺼내던 것을 없앰. 주문은 됐는데 못 꺼낸 것이 있으면 "무료로 받기"가 그대로 보이고, 누르면 Xsolla 무료 주문은 하루 제한으로 넘어가고 서버 `event_claim`이 인벤토리에서 꺼냄 (두 번 받지 않음)
  - 캐시로 바꾸기 칸: 사탕이 0개면 0 (전에는 1)
- `index.html` 마을 배너: 첫날 0시~10시는 "🎃 할로윈 이벤트 · 오전 10시부터 호박 사탕 받기" (영어·일본어 번역 추가)
- 서버 PHP는 그대로
