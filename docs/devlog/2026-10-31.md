- 상점이 `open: false`를 모두 "받기 기간이 끝났어요"로 보여 줘서, 이미 받은(또는 끝난) 것처럼 보였음. 실제로 받은 것은 없음 (사탕 0개, `event_claims` 기록 없음)

## 스킨은 다른 사람에게도 보이게, 한글·일본어 입력 상태에서도 단축키 (dc#137)

### 사용자 요청
- "스킨에 대해서 사용자만 보인다고 했는데 어차피 사용자만 보인다면 그냥 스킨을 착용한 사용자는 모든 사용자가 그렇게 보여지도록 수정해줘."
- "그리고 PC로 플레이할때 ASDW 로도 가능하도록 수정해줘."
- "다른 버튼들도 한글키 일본어키일때 작동되도록 수정해줘."

### 스킨: 마을의 다른 사람에게도
- 전에는 스킨이 내 화면의 내 그림에만 보이고, 마을의 다른 사람은 모두 같은 기사 그림
- `index.html` 마을 위치 보내기(`lobby`): 쓰고 있는 스킨 id를 `skins`로 함께 보냄
- `ranking-php/api.php` `lobby_ping`: 로그인 계정이 보낸 스킨 중 그 계정이 가진 것(`event_skins_of`)만 `presence.skin`에 (최대 2개, 모르는 id·남의 스킨·게스트는 무시). 다른 사람 목록의 로비 사람마다 `skins`
  - `presence`에 `skin` 칸 추가 (`ALTER TABLE`, 처음 부를 때 저절로)
- 다른 사람 그림(`person`): 기사 그림 위에 호박 머리·사신의 낫. 낫이면 기사 그림 왼쪽 위의 칼을 지우고 낫. 스킨 조합마다 한 번만 만들어 둠
- 스킨을 벗으면(보내지 않으면) 다음 위치 보내기(1초)부터 원래 기사 그림

### 단축키: 한글·일본어 입력 상태
- WASD 이동은 원래 있었지만(던전·마을·점프 던전·3D), 한글 입력 상태에서는 키가 ㅈ·ㅁ·ㄴ·ㅇ로, 일본어 입력에서는 가나·"Process"로 와서 안 먹었음 (I·B·M·V·Q·P 같은 다른 단축키도 같음)
- `index.html` `keyName(e)`: 글자가 영문이 아니거나 "Process"·"Unidentified"면 자판 위치(`e.code`: KeyA…, Digit, Period, Space, Enter)로 읽음. 키 처리(마을·점프 던전·3D·던전·도감·인벤토리·확인 창)가 모두 이걸 씀
- 안내 문구에 A·D·W·S도 (마을·튜토리얼·점프 던전, 영어·일본어)

### 서버에 올릴 것
- `ranking-php/api.php`

### 테스트
- `event-api-test`(40개): 가진 스킨만 다른 사람에게 보임(모르는 id 버림), 스킨 없는 계정·게스트는 안 보임, 벗으면 원래대로

## 끝이 없는 구멍 경험치 3배 → 150배 (dc#138)

### 사용자 요청
- "마지막 구멍 던전은 사용자 케릭터의 레벨을 올리기 위한 던전인데.. 경험치가 너무 적게 올라"
- 다음 레벨까지 필요한 경험치가 레벨마다 1.5배라 높은 레벨에서는 거의 안 오름 (레벨 28이 20층을 다 깨도 약 2레벨). 선택지(레벨에 맞춰 주기·5배·레벨 곡선 완화) 중 사용자가 "구멍 경험치 50배"를 고름

### 바꾼 것
- `monsters.js` `ABYSS.xpMul` 3 → 150 (헬 50층 몬스터 경험치의 150배 × 층 배율). 일반·정예·네임드 모두 (`abyssXp`)
- 다른 던전·레벨 곡선(×1.5)·레벨 보너스는 그대로. 들어갈 때 안내 "경험치를 150배"는 `ABYSS.xpMul`에서
- 어림 (한 층에 몬스터 약 50 + 네임드 2): 1층 약 250만, 20층 약 630만, 20층 모두 약 8,650만
  - 레벨 25·28·30에서 20층을 다 깨면 약 38, 레벨 33·35면 약 39 (높아질수록 다시 느려짐: 레벨 곡선이 1.5배라서)
  - 1층 하나: 레벨 28이면 약 4.7레벨, 레벨 33이면 약 0.6레벨

### 테스트
- `abyss-e2e`(40개): `ABYSS.xpMul` 150, 일반 몬스터 경험치 = 헬 50층 × 150, 들어갈 때 안내 "경험치를 150배"
- 블로그 그림: `tools/blog-shots.mjs` 장면 `abyss-xp` (웨이포인트로 구멍에 들어간 뒤 기록 창)
