## 무료 선물 광고를 진짜 보상형 광고로 (dc#118)

### 사용자 요청
- "무료 선물 광고를 진짜 보상형 광고로 바꿔줘"

### 바꾼 것
- `ads-config.js`: `provider: "test"` → `{ provider: "h5", client: "ca-pub-…", test: false }`. 구글 AdSense H5 게임 광고(Ad Placement API)의 보상형 광고
  - 광고 코드(`Ads.showH5`)는 하루 입장·광고 보상을 만들 때 미리 넣어 둔 것. 무료 선물·하루 입장·부활·거래 수수료가 모두 같은 `Ads.watch`라 함께 바뀜
- `index.html` `Ads`
  - 구글 광고를 못 불러오면(`breakStatus`가 viewed·dismissed가 아님: H5 게임 광고 승인 전, 보여 줄 광고 없음, 광고 차단, 스크립트 실패) 예전 5초 안내 화면으로 대신하고 보상은 그대로. 중간에 닫으면(dismissed) 보상 없음
  - 광고가 떠 있는 동안(`beforeAd`~`afterAd`) `Ads.isOpen()`이 참 → 3D 화면 시간·키 멈춤, 소리 멈춤(`RLSound.pause`)
  - 주소에 `?adtest=1`이면 구글 테스트 광고(`data-adbreak-test="on"`): 실제 사이트에서 광고가 뜨는지 확인용
  - 안내 화면 문구: "테스트 광고 · 구글 광고 승인을 받으면…" → "광고 대신 · 지금은 광고를 불러올 수 없어요. 잠깐만 기다리면 보상을 받아요." (en·ja)
- `test/ko-default.cjs`: 모든 테스트에서 구글 광고 주소를 막음 (진짜 광고를 부르지 않고, 안내 화면으로 대신하는 길로 기존 테스트가 그대로 돎)

### 테스트
- `gift-e2e`(34개, 새 9개): 구글 광고 스크립트 대신 가짜 스크립트로
  - 끝까지 봄: 안내 화면 없이 광고, 광고 중에는 게임이 멈춤(`Ads.isOpen`), 선물 3개, 게시자 ID·테스트 모드 아님

## PC 브라우저에서 광고 버튼이 멈춤 (dc#119)

### 사용자 요청
- "모바일에서는 잘작동하는 것 같은데 PC 웹.브라우저에서는 광고 버튼이 멈추고 작동하지 않아"

### 원인
- 구글 광고 스크립트가 아무 답(콜백)도 하지 않으면 `Ads.showH5`가 끝없이 기다렸음
  - PC의 광고 차단 확장 프로그램은 광고 스크립트를 막지 않고 오류 없는 빈 껍데기로 바꿔치기하기도 함 → `onerror`도 안 오고 `adBreak` 콜백도 안 옴
  - 보여 달라고 했는데(`showAdFn`) 광고가 끝내 안 뜨는 경우도 같음

### 바꾼 것
- `index.html` `Ads`: 광고를 부르거나 보여 달라고 한 뒤 6초(`H5_WAIT`) 안에 광고가 안 뜨면 "광고 없음" → 5초 안내 화면으로 대신 (보상 그대로)
  - 광고가 떠 있는 동안은 기다림, 광고가 닫힌 뒤 `adBreakDone`이 안 오면 2초 뒤 끝냄. 늦게 온 콜백은 무시
  - 광고 스크립트 자체가 6초 안에 안 오면(느린 망·차단) 기다리지 않음

### 테스트
- `gift-e2e`(40개, 새 6개): 가짜 스크립트가 아무 답도 안 함(silent)·광고가 안 뜸(noShow) → 약 6초 뒤 안내 화면, 선물은 그대로
  - 예전 코드로 돌리면 12초가 지나도 안내 화면이 안 떠서 실패하는 것도 확인

## 게임 페이지 머리에 애드센스 코드, 블로그에 자동 광고 코드 (dc#120)

### 사용자 요청
- (AdSense "광고 설정 미리보기" 화면: game.apacimtest.com, 빨간 "코드 가져오기", 자동 광고 사용 안 함) → 게임 페이지 머리에 코드를 넣고 자동 광고는 게임에서 끄기, 블로그에만 자동 광고를 쓰는 안(B) 중에서 "B 안으로 진행해줘"

### 원인
- 게임은 광고 코드(adsbygoogle.js)를 광고 버튼을 누를 때만 불러와서, AdSense가 페이지를 읽을 때 코드가 안 보였음

### 바꾼 것
- `index.html` 머리(`<head>`): `ads-config.js`를 먼저 읽고, `provider`가 `"h5"`면 페이지를 열 때 광고 코드를 불러옴 (`window.RL_ADSENSE`: 불러오면 true, 실패면 false)
  - 열 때부터 보상형 광고를 미리 준비(`preloadAdBreaks`)해서 버튼을 누르면 더 빨리 뜨게
  - `?adtest=1`·`ADS.test`도 여기서 (`data-adbreak-test`)
  - 포털 빌드는 `ads-config.js`를 `provider: "portal"`로 바꿔서 구글 광고 코드를 안 불러옴 (포털 빌드 저장소의 확인 테스트 18/18: 포털 SDK 말고 바깥 요청 없음)
  - 포털 모드(`window.RL_PORTAL`이 먼저 있으면)도 안 불러옴: GitHub Actions의 `portal-e2e`가 원본 `ads-config.js`(h5)로 포털 모드를 띄우다 구글 광고 주소를 불러 실패해서 더함
- `Ads.loadH5`: 머리에서 불러 둔 것을 기다림 (최대 6초)
- `tools/blog-build.mjs`: 공개 페이지(글·목록·게임 이미지)에 애드센스 자동 광고 코드. 네이버 옮기기 페이지(noindex)는 뺌
- AdSense 화면에서 할 일(사용자): 블로그에 자동 광고 켜기, 게임 첫 화면·상점·랭킹 등은 "제외된 페이지"로

### 테스트
- `gift-e2e`(41개): 페이지를 열면 광고 버튼을 누르기 전에 머리에 광고 코드가 있음
- `blog-e2e`(31개): 공개 페이지에는 애드센스 코드, 네이버 옮기기 페이지에는 없음
- `ads-e2e`·`i18n`·`lobby`·`sound`·`portal-e2e`(20개, 바깥 요청 없음) 통과

## 광고를 불러오는 동안 기다림 창과 취소 (dc#121)

### 사용자 요청
- ""무료 광고"를 누르면 띄워지는데 시간이 걸리는 것 같아. 동영상이 띄워지는데 기다려달라는 창을 띄우고 "취소" 버튼도 같이 생성해줄수 있어?"

### 바꾼 것
- `index.html`: 새 창 `#ad-wait` (도는 원 · "광고를 불러오는 중이에요. 잠시만 기다려 주세요." · 취소). en·ja
  - `Ads.watch`: 누르자마자 띄움 → 서버 티켓(`ad_start`)과 구글 광고를 기다리는 동안 보임 → 광고가 뜨면(`beforeAd`) 닫힘. 광고를 못 불러와 안내 화면으로 넘어갈 때도 닫힘
  - 취소(버튼·Esc): 바로 닫고 "광고를 취소했어요." · 보상 없음. 서버·광고를 더 기다리지 않음(`Promise.race`), 늦게 온 광고는 띄우지 않음(`showH5`가 취소를 확인), 취소한 뒤 늦게 난 서버 오류는 무시
  - 창이 떠 있는 동안 `Ads.isOpen()` → 게임 시간·키 멈춤
  - 서버 최소 시간은 티켓을 받은 때부터 셈 (전처럼)

### 테스트
- `gift-e2e`(48개, 새 7개): 가짜 스크립트 slow(2.5초 뒤 광고)
  - 누르자마자 기다림 창·취소 버튼, 광고가 뜨면 저절로 닫힘, 다 보면 선물
  - 취소: 바로 닫힘·"광고를 취소했어요"·선물 없음, 4초 뒤에도 늦은 광고·안내 화면이 안 뜨고 게임이 멈춰 있지 않음
- `ads-e2e`·`i18n`·`portal-e2e`·`market-e2e` 통과
