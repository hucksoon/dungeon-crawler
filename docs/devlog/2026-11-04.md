## 부활 손보기 (dc#162)

### 사용자 요청
- 부활을 손봐야할 것 같아. 사용자가 랭킹을 위해 어쩔수 없이 부활이 필요할때만 사용할 수 있게 5캐시나 광고를 보고 아무런 피해없이 같은 축복, 유물, 능력치를 다 가지고 부활해.
- 그리고 운영자는 그냥 가능하게 해주고.
- 물어본 것에 대한 답: 한 판에 한 번이고 랭킹에 올라가도 부활함이 적혀 있어야 해 · 광고 부활은 하루 제한 없음 · 부활하면 그 자리에서 이어서

### 예전 (dc#47~)
- 캐시 10개(부활권) 또는 광고(하루 1번), 한 판에 한 번
- 부활하면 그 층을 **처음부터** 새로 만들어 시작 (몬스터도 새로). 축복·유물·레벨·골드는 원래도 그대로였음
- 쓰러진 채로 새로고침하면 층이 지워져 있어서 새 층

### 바꾼 것 (`index.html` 부활 · `ranking-php/ads.php` · `ranking-php/api.php` · `ranking.html` · `tools/xsolla-catalog.mjs`)
- **쓰러진 자리에서 이어서**: 같은 층·같은 칸, 이 층에서 잡은 몬스터·떨어진 아이템 그대로, HP 가득·포션·회피 바로 준비·화상/느려짐 풀림
  - 다시 바로 쓰러지지 않게: 무적 2초 + 3턴, 2칸 안에 있던 몬스터는 걸어서 4칸 넘게 떨어진 빈 바닥으로 밀어냄, 날아오던 탄·강타·저주 구슬 예고는 지움
  - 부활할 수 있는 동안은 쓰러진 층을 저장해 둠 → 쓰러진 채로 새로고침해도 그 층 그대로 (예전에는 쓰러지면 층을 지움). 층이 없으면(예전 저장·다른 기기) 예전처럼 그 층을 새로
- **5캐시** (부활권 가격 10 → 5, Xsolla 카탈로그 값. 게임은 카탈로그에서 읽고, 못 읽으면 기본값 5)
- **광고 부활 하루 상한 없음** (서버 `AD_CAPS['revive']` 1 → 1000). 한 판에 한 번은 게임이 그대로 지킴. 버튼은 "광고 보고 부활" (남은 횟수 표시 뺌)
- **랭킹에 부활 표시**: 부활한 판이면 랭킹에 보내는 내용에 `rv: 1` → 서버가 그 판의 장비 기록(`stage_gear`)에 `revived: true`를 같이 남김. 최고 층을 새로 세울 때만 장비 기록이 바뀌니, 부활한 판에서 세운 기록에만 붙고 부활 없이 더 높이 가면 사라짐. 나이트메어·헬·끝이 없는 구멍 랭킹도 같음
  - 랭킹 화면: 층 아래 초록 "♻ 부활", 사람을 누르면 "최고 46층 · ♻ 부활"
- **운영자 기기**: 그 자리에서 무료 부활 (몇 번이든). 예전 "쓰러진 층으로 바로" 버튼도 그대로
- 쓰러진 화면 안내: "쓰러진 자리에서 HP 가득 찬 채로 이어서 해요. 축복·유물·레벨·능력치·골드, 이 층에서 잡은 몬스터도 그대로예요. 한 판에 한 번, 이 판의 랭킹 기록에는 ♻ 부활 표시가 붙어요." (게스트에게도)
- 부활권 이름은 그대로, 설명을 바꿈 (en·ko·ja)

## 가방에는 펫과 스킨만 · 펫 (dc#164)

### 사용자 요청
- 자동으로 장비를 착용하게되면 기존 장비가 인벤에 남아. 인벤에는 스킨만 보여주기로 하지 않았어?
- 물어본 것에 대한 답: 가방은 스킨과 펫만 있어. 펫은 보스 포함 정예 몬스터가 낮은 확율로 드랍하는데 지도 상에 사용자가 먹지 않은 아이템을 대신 먹어줘.
- 펫은 작은 사이즈의 몬스터가 사용자를 따라다니는 모습이야. 이벤트 시에는 해당 스킨을 그대로 가져가. 예를 들면 지금 할로윈 몬스터들이야. 희귀성을 높이는거지.
- 펫도 등급이 있어서 아이템을 얻는 범위와 이동 속도 차이를 줘. 펫은 자동으로 장착하지만 한번 얻으면 중복으로 얻지 않고 사용자가 원하는 펫을 고정하는 기능도 있어.
- 스킨하고 펫은 서버에 저장되면 좋을 것 같은데 많은 수정이 필요할까?
- (A: 계정 저장에 같이 / B: 서버가 펫 목록을 따로 관리 중에서) B로 해줘. 끝나면 PR 만들고 머지해줘.

### 살펴본 것
- 자동 장비를 켜고 새로 주워 보면 바꿔 낀 옛 장비는 강화석으로 분해되고 가방에 남지 않았음 (40개 주워도 가방 0/48)
- 가방에 남아 있던 장비는 정식 v2 전에 모은 것, 우편함(상점 장비 상자·무료 선물·운영자 선물)에서 온 것, 예전에 잠근 것

### 바꾼 것 (`index.html` 인벤토리·펫, `monsters.js PETS`)
- **가방 = 펫 + 스킨**: 인벤토리의 가방 칸에 "🐾 펫"과 "꾸미기(스킨)"만. 가방 전부 판매 버튼·자동 장비 스위치는 숨김 (자동 장비를 끈 테스트 설정만 예전 가방)
- **가방 정리**: 게임을 열 때·인벤토리를 열 때 가방에 남은 장비를 자동 장비처럼 끼거나(중복이면 강화) 분해. 우편함으로 온 장비도 바로. 예전에 잠근 것도 분해 (자물쇠는 dc#140부터 쓸 수 없었음). 로그 "🎒 가방 정리: 장비 n개 — m개는 끼고 나머지는 분해했다 (강화석 +k)"
- **펫 = 쓰러뜨린 몬스터**: 정예 0.1% · 보스 3% · 네임드 10% 확률로 그 몬스터가 펫이 됨. 몬스터 그림을 작게(0.6칸) 그려 나를 따라다님 (통통 뛰며 걷는 쪽을 봄, 등급 색으로 은은하게 빛남). 황금 고블린·분신은 없음
  - **이벤트 펫**: 이벤트 중에 얻으면 그 이벤트 모습(할로윈이면 마녀 모자를 쓴 몬스터)을 그대로 가져가고 등급 한 단계 위. 같은 몬스터라도 다른 펫("🎃 할로윈 트롤")이라 이벤트 때만 모음. 이벤트가 끝나도 그 모습 그대로
  - **같은 펫은 한 번만**: 이미 가진 펫(같은 몬스터·같은 모습)은 다시 나오지 않음
  - **등급** (일반 · 희귀 · 영웅 · 전설): 주우러 가는 범위 내 둘레 4 · 7 · 11칸 · 지도 전체, 한 턴에 1 · 2 · 2 · 3칸. 등급 비율: 정예 일반 70 · 희귀 25 · 영웅 5, 보스 희귀 45 · 영웅 40 · 전설 15, 네임드 영웅 40 · 전설 60
  - **자동 장착 · 고정**: 가장 좋은 펫(등급 → 최근에 얻은 것)을 저절로 데리고 다님. 가방에서 펫을 누르면 그 펫으로 📌 고정 (더 좋은 펫이 와도 그대로), 고정한 펫을 다시 누르면 고정을 풀고 가장 좋은 펫으로
  - 하는 일: 범위 안에 **남은 아이템**(경험치 구슬·골드·장비·보물·보석·룬)을 가장 가까운 것부터 주우러 감. 장비는 자동 장비로. **회복 구슬은 줍지 않음** (위험을 무릅쓰고 주우러 갈지 고르는 것, dc#155). 벽은 못 지나가고(모서리 대각선도) 몬스터는 지나감. 몬스터는 펫을 공격하지 않음. 주울 게 없으면 내 둘레 2칸 안으로 따라옴. 3D 화면에는 그리지 않음 (줍기는 그대로)
  - 이 기기에는 가방 저장에 같이 남음 `{ have: { 이름표: { g: 등급, at, s: 떨어뜨린 종류 } }, on, pin }`. 계정 저장(profile.php)에는 넣지 않음 (아래 서버 펫 목록이 기준)
- **서버가 펫 목록을 관리 (B)** (`ranking-php/pets.php` 새로, 표 `pets`·`pet_prefs`): 로그인 사용자만
  - `GET pets` 목록 · `POST pet_claim { key, g, src }` 새 펫 · `POST pet_set { key | null }` 고정·풀기. 결과는 늘 전체 목록 `{ have, on, pin }`
  - 서버가 확인: 펫이 될 수 있는 몬스터(monsters.js `petMonsters()`와 같은 48종), 이벤트 모습은 그 이벤트 기간에만(끝난 다음 날까지), 떨어뜨린 종류(정예·보스·네임드)에서 나올 수 있는 등급(이벤트 모습은 한 단계 위), 같은 펫은 한 번만(409), 하루 20마리까지(429). 고정은 가진 펫만(404)
  - 게임(`PetSync`): 들어올 때 서버 목록을 받고 이 기기에만 있는 펫(게스트로 얻은 것·연결이 끊겼을 때 얻은 것)을 올림. 새 펫·고정·풀기는 바로 서버에도. 서버가 거절하면(같은 펫이 이미 있음·이벤트 기간 끝·등급) 서버 목록으로 되돌림, 연결이 끊기거나 하루 한도면 기기에 두고 다음에 다시
  - 원래 계정 id는 저장하지 않음 (다른 표처럼 HMAC 키). 몬스터를 정말 쓰러뜨렸는지는 서버가 판 진행을 몰라서 확인하지 못함 (펫은 줍기만 돕고 랭킹·능력치와 상관없음)
  - 펫만 바뀌면 계정 저장(profile.php)은 올리지 않음 (처음에는 서버 목록을 받을 때마다 계정 저장이 2초 뒤에 올라가서 `profile-e2e`의 "던전에서 움직여도 1분 동안 안 올림"이 깨졌음)
  - 스킨(이벤트 꾸미기)은 원래부터 서버(`event.php`, 표 `event_skins`)가 관리하고 있어서 바꾸지 않음
- 처음에는 동물 펫 6종(슬라임·고양이·꼬마 용 등)으로 만들었다가 위 요청대로 "쓰러뜨린 몬스터가 작은 펫"으로 바꿈 (동물 그림은 지움)
- 영어·일본어: 펫 이름(이벤트 모습), 등급, 가방 화면, 로그
