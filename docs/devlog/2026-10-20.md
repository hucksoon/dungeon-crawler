### 나이트메어 골드: 처치 ×3, 골드 더미 ×8, 판매 ×3 (dc#24)
- 피드백: 나이트메어에서 얻는 `$`(골드 더미)가 너무 적고, 아이템 판매 골드도 너무 적다. 나이트메어를 깨면 기대 골드는?
- 계산해 보니 (장비의 골드 획득 +% 빼고)
  - 나이트메어 한 층 골드 약 1,000(1층) ~ 4,600(50층). **일반 75층 한 층(약 5,300)보다 적었어요.** 나이트메어는 한 층 몬스터가 20~50마리라 일반 75층(80~150마리)보다 적어서
  - 골드 더미는 한 층에 약 180~290골드뿐이었고, 나이트메어 1~50층을 다 깨도 약 **12만**으로 일반 1~75층 한 번(약 13만)보다 적었어요
  - 쓰는 곳은: 나이트메어 레전더리 상점 6,800~10,700, 고대 굴리기 2,300~3,600 (모두 ×2)
- 바꾼 것 (나이트메어 몬스터가 나오는 곳 = 나이트메어 던전과 골드 던전 오른쪽 문)
  - **몬스터 처치 골드 ×3** (보스·황금 고블린 포함), **골드 더미 ×8**
  - **나이트메어 아이템 판매 골드 ×3** (예: 100레벨 레전더리 435 → 1,305)
- 결과: 한 층 약 3,900(1층) · 7,700(10층) · 10,700(25층) · 15,300(50층), **1~50층을 한 번 깨면 약 42만 골드** (일반 1~75층의 약 3배). 25층에서 한 층이면 나이트메어 레전더리 하나(8,720)를 살 만큼
  - 나이트메어 골드 던전(악몽 25층 58,200)은 여전히 한 번에 나이트메어 5층 분량이라 골드 모으기에는 더 빨라요
- 경제 문서에 나이트메어 층별 골드 표를 추가했어요
- 테스트: 처치 ×3·더미 ×8·판매 ×3 (규칙·실제 게임)

### 가방 기록 200개 제한, 로비 그리기 줄이기 (dc#25)
- 페이지가 무거운지 실제 브라우저로 재 봤어요: 파일 4개 약 290KB(전송은 압축돼서 약 70KB), 메모리 1~2MB(던전 3,000번 행동해도 그대로), 화면 요소 약 540개로 일정, 던전에서 가만히 있으면 CPU 약 2%
- 고친 것 두 가지
  - **가방 기록이 끝없이 쌓였어요.** 아이템을 줍고·팔고·강화할 때마다 한 줄(약 200글자)씩, 75층 한 번에 약 2,000줄. 10번쯤 돌면 브라우저 저장소 한도(약 5MB)에 닿아 **가방 저장이 조용히 실패할 수 있었어요.** 기록은 게임에서 읽지 않아서 최근 200줄만 남겨요 (예전에 쌓인 것도 불러올 때 정리)
  - **로비는 매 프레임(초당 60번) 화면 전체를 다시 그려서 CPU 약 21%** → 초당 20번만 그려서 **약 7%**. 휴대폰 배터리 아낌 (움직이면 바로 다시 그림)

### 전설의 힘 (레전더리 완성도, dc#25)
- 피드백: 세트가 너무 강해서 레전더리는 거쳐 가는 수준이다. 모든 능력치가 잘 붙은 레전더리는 세트보다 좋게 할 수 있나
- 시뮬레이션: 레전더리는 세트보다 추가 능력치가 1줄 많고 주 능력치도 조금 높지만, 고대(모두 최대) 레전더리 5부위도 세트와 비슷한 수준이었어요 (25층 보스 9턴, 5마리 24%)
- **전설의 힘**: v4 레전더리의 **완성도**(주·추가 능력치가 범위 안에서 얼마나 높은지 평균, 고대 = 100%)에 따라, 레전더리 하나마다 **공격력·방어력·최대 HP +최대 12%**
  - 완성도 60% 밑은 0, 100%에 가까울수록 가파르게 (80% +3%, 90% +7%, 100% +12%) — 처음엔 완성도에 그대로 비례시켰더니 평범한 레전더리(완성도 약 50%)도 세트만큼 좋아져서
  - 결과 (25층, +6): 고대 레전더리 5부위 보스 6턴·5마리 0% (가장 고르게 강함), 보통 레전더리 5부위 8턴·22%, 세트는 각자 한 가지에서 앞섬 (화염 무리 3턴, 뇌전 보스 5턴). 하나에 +20%면 모든 세트를 압도해서 12%
- **모든 속성 저항도**: 하나에 +20%로 하면 고대 레전더리 4개만으로 세 저항이 모두 75%라 저항 줄이 쓸모없어져서, **하나에 +4%** (고대 레전더리 5부위 = +20%), 같은 곡선
- 이미 가진 레전더리도 바로 적용 (효과를 계산할 때 더함). 아이템 상세에 "완성도 87% · 전설의 힘 …", 인벤토리 능력치와 랭킹 장비 보기에도

### 속성 저항 줄 조정 (규칙 r4, dc#25)
- 피드백: 저항을 너무 쉽게 75% 찍는다. 강화로 저항도 오르기 때문인데, 강화에서 빼면 너무 어려워질까
- 시뮬레이션 (저항만 노려서 7부위 고름, +10): **강화에서 빼도 거의 그대로**였어요 (부위마다 10개 중 30번 중 29번 75%). 원인은 저항 줄 자체(11~34%, 평균 22%)
  - 범위 ×0.6(7~20%) + 강화로 안 오름: 부위마다 10개 → 4/30, 20개 → 15/30, 40개 → 25/30 — "열심히 모으면 맞출 수 있는" 정도 / ×0.45(5~15%)는 40개 중에서도 1/30이라 너무 어려움
- 바꾼 것: **속성 저항 7~20%, 모든 속성 저항 4~7%** (r4부터 새로 얻는 아이템), **강화로 오를 줄을 고를 때 저항 줄은 뺌** (이미 강화한 아이템도). r3까지 얻은 아이템의 저항 줄은 효과를 새 최대치(20% · 7%)까지만 ("적용 20%")
- 속성 세트 4세트의 저항 +20%는 그대로 (그 속성 하나는 맞추기 쉬운 세트 고유 장점)
- 테스트: 저항·전설의 힘 17개 (r4 범위, r3 적용 20%, 강화가 저항 줄을 안 올림, 완성도·전설의 힘·저항, 화면, 서버)

### 인벤토리가 길어진 것 고치기
- 피드백: 아이템 이름이 길어지니(고대 +10 악몽의 번개 화염의 투구) 인벤토리가 길어졌다
- 원인: 장비 칸이 **오른쪽 능력치 칸 높이에 맞춰 늘어나고** 있었고, 능력치 칸에 세트 설명이 단계마다 모두(켜지지 않은 단계까지) 쌓여 있었어요
- 고친 것: 장비 칸은 내용만큼만, 이름은 두 줄까지(마우스를 올리면 전체 이름), 능력치 칸의 세트는 **켜진 효과 + 바로 다음 단계**만. 세트의 모든 단계는 세트 아이템 상세에서 (켜진 단계는 밝게)
