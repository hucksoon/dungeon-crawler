- 시작 조합 18개에서 한 부위씩 바꿔 보며 나아지면 바꿈 (부위마다 후보 6~14개: 레전더리, 세트 조각, 유니크, 룬워드)
- **최종: 유니크 7부위** (여우구슬 지팡이 · 사자의 낫 · 비녀 · 쇠비늘 · 사슬 · 관복 · 용비늘) → 0% / 0%, 14턴 / 11턴

- **유니크 없이 1위**: 무기 룬워드 태산(단검) + 가슴 룬워드 천하무적 + 나머지 레전더리 → 0% / 1% (55턴 · 30턴, 안전하지만 느림). 천하무적에는 "하" 룬(0.3%)
- **세트가 크게 밀림**: 시험의 세트 6 67% / 87%, 속성 세트 5 95~100%, 견고 100%. 원인은 **전설의 힘** — 줄 품질 95% 레전더리는 하나마다 약 +9%라 5부위를 세트로 바꾸면 공격·방어·HP가 40% 넘게 빠짐

### 세트의 힘·폭풍전야 2칸 (dc#43)
- 사용자 의견: 세트에 힘을 주면 나이트메어가 쉬워짐 → **지옥의 세트(헬 장비)에만**. 나이트메어·일반 세트는 그대로
- **세트의 힘**: 지옥의 세트 조각 하나마다 공격력·방어력·최대 HP +12%, 모든 속성 저항 +4% (고대 레전더리의 전설의 힘 최대치와 같음). +9%로는 화염·뇌전 세트가 74~99%라 부족
- 속성 세트를 쓰려면 **폭풍전야**(속성 저항 −20%)가 짝이라는 사용자 설계: 실제로 그대로 맞음. 헬 몬스터 속성 저항 때문에 한 속성 스킬이 평균 43%(보스 53%) 깎이는데, 폭풍전야로 화염 세트 몰려옴 43% → 5%, 뇌전 88% → 42%
- 폭풍전야 범위 **주변 8칸 → 2칸** (파이어볼·체인 범위와 맞춤)
- 결과 (헬 50층, 줄 품질 95%, 몰려옴 / 염라대왕):

| 조합 | 전 | 뒤 |
|---|---|---|
| 전부 레전더리 | 21% / 28% | 21% / 28% |
| 시험의 세트 6 | 67% / 87% | 0% / 5% |
| 서리 5 + 두 손 단검 | 95% / 96% | 1% / 21% |
| 화염 5 + 두 손 단검 | 100% / 100% | 43% / 44% |
| 화염 5 + 폭풍전야 + 레전더리 방패 | 100% / 99% | 5% / 40% |
| 화염 5 + 폭풍전야 + 업경대 | 82% / 88% | 0% / 9% |
| 뇌전 5 + 폭풍전야 + 업경대 | 99% / 80% | 1% / 5% |
| 서리 5 + 폭풍전야 + 업경대 | 29% / 86% | 0% / 6% |

  - 폭풍전야는 장검이라 방패와 껴야 해서 두 번째 공격이 없어져 보스는 느림 → 유니크 방패 업경대까지 끼면 완성 ("속성 세트 + 폭풍전야 + 업경대")
  - 유니크 7부위(0% / 0%)보다는 약함 → 유니크가 최종 목표 그대로
- 서버: 랭킹 장비 보기의 능력치 계산(`r_totals`)에도 세트의 힘. JS·PHP 7,500개 비교 모두 같음
- 테스트: 유니크 e2e에 5개 더 (세트의 힘 규칙·능력치 화면, 폭풍전야 2칸)

### 장신구 1단계: 목걸이·반지 (dc#44)
- 사용자 제안: 전설의 힘(레전더리)·세트의 힘(지옥의 세트)을 **장신구 칸**으로 옮기자 → 어떤 장비를 입든 같은 힘을 얻어서 레전더리·세트·유니크 비교가 공정해짐
- 시뮬레이션으로 먼저 확인: 두 힘(그리고 유니크의 힘)을 빼고 장신구 3개(공방HP% 레전더리 18~25)를 넣으면 줄 품질 95%에서 지금과 거의 같음 (헬 50층 22% / 30% → 23% / 28%). 일반 던전은 전설의 힘이 거의 없던 곳이라 보스가 쉬워져서(75층 에픽 장비 100% → 57%) 일반 던전 장신구는 공방HP 절반. 유니크는 힘 없이도 레전더리보다 확실히 좋음 (1.2배 주 능력치·고유 효과)
- 이번 단계 (규칙 r7):
  - 장착 칸 **목걸이 1, 반지 2** (반지 두 칸이 차 있으면 "반지 1 / 반지 2 자리에 끼기"). 부위 후보 7 → 9 (예전 아이템은 r6 그대로)
  - 등급 커먼 ~ 레전더리. **★ 주 능력치 = 공격력·방어력·최대 HP +%** (레전더리 15~25%, 일반 던전 5~15%, 범위 안에서 고르게 굴림)
  - **◆ 추가 능력치 = 속성 저항 줄만** (불·얼음·번개 최대 30%, 모든 속성 최대 11%, 같은 종류 중복 가능). 줄 수는 얻은 곳에 따라 확률: 일반 0~1, 나이트메어 1~2, 헬 1~3 (사용자 결정). 처음엔 저항을 주 능력치, 공방HP + 치명타 등 무작위 줄을 추가 능력치로 잘못 넣었다가 사용자가 바로잡음
  - 강화로 오르지 않음. 장신구에는 전설의 힘 없음
  - **고대는 드롭으로만**: 장신구(레전더리 3%)와 유니크(r7부터 3%). 고대 다시 굴리기·옵션 재련 없음.
  - 고대 = 모든 능력치가 최대치 (다른 장비와 같은 규칙). 장신구는 줄이 1~3개라 우연히 최대치가 되기 쉬워서(약 20%) — 처음엔 "고대 굴림에 걸린 것만"으로 막았다가, 사용자 의견대로 규칙은 그대로 두고 **범위 안에서 고르게 굴리고 범위를 넓혀**(최대치 20% → 1/칸 수) 낮춤: 레전더리 장신구 중 고대 일반 7.8% · 나이트메어 3.4% · 헬 3.9% **운영자만 "고대로 만들기"** 버튼 (고대가 나오는 굴림 번호를 기록 → 서버도 같은 계산)
  - 서버: 생성 규칙·검증 r7, 랭킹 장비 보기에 반지 두 개, 저장 장착 칸 10개, 거래소 부위 검색에 목걸이·반지. 일반 사용자가 장신구·유니크에 고대 굴림 횟수를 보내면 거절
- 확인: JS·PHP 9,500개 같음 (장신구·고대 유니크·운영자 고대 포함), 장신구 e2e 21개, 운영자 e2e +4개 (장신구·유니크 고대로 만들기)
- 다음: 유니크 장신구(속성 저항 2~3줄), 그리고 세 힘(전설·세트·유니크) 빼기 + 밸런스 다시

### 장신구 2단계: 유니크 장신구 (dc#45)
- 사용자 결정: 장신구는 모두 추가 능력치가 속성 저항뿐 (유니크만이 아니라) → 1단계 구조를 바로잡음 (★ 공방HP, ◆ 저항 줄)
- 장신구 고대: "고대 = 모든 능력치 최대치" 규칙은 그대로가 맞다는 사용자 의견 → 굴림 조건을 되돌리고, 장신구는 **범위 안에서 고르게** 굴리고 공방HP 범위를 넓혀(레전더리 15~25%, 일반 5~15%) 우연한 고대를 낮춤 (예전 약 20% → 일반 7.8% · 나이트메어 3.4% · 헬 3.9%, 드롭 고대 3% 포함)
  - 다른 장비는 최대치가 20% 확률이라 범위를 넓혀도 그대로 → 장신구만 고르게 굴려야 범위로 확률을 정할 수 있음
- **유니크 장신구 5개** (네임드마다 1개, 유니크 장비 2개와 따로 **10%**):

| 네임드 | 유니크 장신구 | 고유 효과 |
|---|---|---|
| 불가사리 | 쇠이빨 목걸이 | 불 저항 최대치 +5% (75 → 80%) |
| 구미호 | 여우불 반지 | 치명타 확률 +3%, 치명타 피해 +10% |
| 이무기 | 여의 반지 | 번개 저항 최대치 +3% |
| 저승사자 | 명부의 반지 | 흡혈 최대치 +2%p |
| 염라대왕 | 업경 목걸이 | 모든 속성 저항 최대치 +5% |

  - 주 능력치 공방HP 18~30% (레전더리 장신구 × 1.2), 저항 줄 2줄 70% · 3줄 30%
  - **같은 유니크 반지 두 개**를 낄 수 있고 효과가 더해짐 (사용자 질문: 반으로 나눠 두 개 = 지금 수치면 약해지나? → 반지의 힘은 대부분 공방HP·저항 줄이라 고유 효과는 덤. 대신 반으로 나누면 1.5%p 같은 소수가 생겨서, 반지 하나 값을 정하고 두 개면 더하는 쪽으로)
  - 장신구로 저항 75%를 쉽게 채우게 되니, 그 위 최대치를 올리는 효과를 넣음 (새 능력치: 불·얼음·번개·모든 속성 저항 최대치, 흡혈 최대치)
- 서버: 시드 |a 검증 (네임드 층, 10% 안의 순번만), 유니크 장신구 생성, 능력치(저항 최대치·흡혈 최대치). JS·PHP 10,300개 같음
- 테스트: 장신구 e2e 33개 (유니크 장신구 규칙·드롭·두 개 겹치기·흡혈 최대치·저항 최대치 80% 표시·서버 인정과 거절)
