  - 계단을 누르면 거기까지 가서 다음 층, 상점을 누르면 상점까지
  - 몬스터를 누르면 움직이는 몬스터를 따라가 옆에서 공격
  - 멈출 때: 맞았을 때, 새 몬스터가 보일 때, 가는 길에 몬스터가 나타날 때, 다른 키·버튼을 누를 때, 창이 열릴 때. 가 본 적 없는 칸·벽은 무시

## 튜토리얼은 직접 해 봐야 닫힘 (dc#94)

### 사용자 피드백
- "새로운 사용자가 튜토리얼을 읽고 있는데 사라졌대. 튜토리얼인 만큼 사용자가 그대로 진행했는지 확인하고 창을 닫아줘. 튜토리얼을 진행 안 했다면 계속 보여져야 해."

### 원인
- 던전·장비·HP 안내 말풍선이 10초 뒤 저절로 사라졌고, 한 번 띄우면 "봤다"로 저장돼서 새로고침해도 다시 안 떴음

### 바꾼 것
- 말풍선 = 해 볼 단계 목록. 직접 해 보면 ☐ → ✓, 다 하면 "✓ 잘했어요!" 1.5초 뒤 닫힘. 저절로 사라지지 않음
  - 마을: 던전 입구로 들어가기 (② ③ 👆 🗺 🏆는 설명)
  - 던전: 몬스터 쪽으로 이동해서 공격 · 칸 클릭(휴대폰은 밀기나 칸 누르기)으로 걷기 · Tab(지도 버튼)으로 지도 겹쳐 보기 · 계단 밟고 다음 층 (+ HP 막대 설명)
  - 장비 줍기: 인벤토리 열기 · ▲ 장비 비교하고 장착
  - HP 30% 이하: 포션 마시기 또는 포탈로 마을 (그 사이 HP가 다시 오르면 내리고, 다음에 또)
- 새로고침해도 남은 단계부터 이어서 (해 본 단계·진행 중인 안내를 이 기기에 저장). 단계는 안내가 뜨기 전에 해 봤어도 ✓
- 여러 개가 걸리면 급한 것부터 (HP > 장비 > 던전 > 마을), 마을 안내는 마을에서만·던전 안내는 던전에서만
- 오른쪽 위 "건너뛰기 ×": 누르면 그 안내는 끝 (직접 고른 경우)

### 테스트
- `newbie-e2e` 40/40: 마을 안내가 새로고침해도 남음 → 던전에 들어가면 끝, 던전 안내 4단계(☐), 11초 뒤에도 그대로, 건너뛰기, 공격 → ✓ · 새로고침해도 ✓ 유지 · Tab → ✓ · 칸 클릭 → ✓ · 계단 → 잘했어요 → 닫힘 → 새로고침해도 닫힘, 포션 → HP 안내 잘했어요, 인벤토리 열기 ✓ 뒤에도 남아 있다가 장착하면 끝
