- 장비 비교: 가방 아이템을 고르면 "끼면 (지금 낀 것과 비교)" — 공격력·방어력·최대 HP·치명타·치명타 피해·흡혈·패링·받는 피해 감소·골드·경험치·아이템 발견·속성 피해·저항이 오르면 ▲ 초록, 내리면 ▼ 빨강, 세트 스킬이 생기거나 없어지는 것도. 장검·보조무기 규칙과 반지 두 칸(칸마다 비교)도 실제 장착과 같게 계산. 지금 낀 것의 능력치는 바로 아래 접어서
- 가방 목록에 ▲(끼면 더 강해짐)/▼(지금 낀 것이 더 강함) 표시 (공격력 위주의 대략 점수)

## 지도 겹쳐 보기, 화면 밀기 · 칸 눌러 자동 걷기 (dc#92)

### 사용자 요청
- "디아블로처럼 게임 화면 위에 프레임을 나눠서 전체맵을 표시해줄 수 있어?" (디아블로2 자동 지도 화면을 예로)
- "화면을 밀어서(스와이프) 이동하는 방식 추가, 또는 화면에서 가고 싶은 칸을 누르면 그쪽으로 한 칸 → 두 개 같이 적용 가능해?" → "두 개 다 진행해주고 칸을 누르면 자동으로 걸어가게 해줘. 그리고 초반 설명에 두 내용도 포함시켜줘."

### 바꾼 것
- 지도 겹쳐 보기: PC는 Tab, 휴대폰은 위 줄의 "지도" 버튼 (켜면 버튼이 눌린 색). 켠 상태는 기억함
  - 지도 전체를 반 크기로, 가 본 바닥과 벽 사이를 반투명 선으로 게임 화면 위에 겹침. 지도의 내 점(흰 점 + 하늘색 고리)이 화면의 내 캐릭터 위에 오게 밀어서 그림 (디아블로처럼)
  - 계단(>)·상점·떨어진 장비(등급 색 점) 표시. 전체 지도(M)를 켰을 때는 겹치지 않음
- 화면 밀기(휴대폰): 던전 화면을 밀면 그 방향으로 한 칸, 손가락을 떼지 않으면 방향 버튼을 누르고 있을 때처럼 계속. 던전 화면을 끌어도 페이지가 움직이지 않음 (마을·점프 던전은 그대로)
- 칸 눌러 자동 걷기 (휴대폰 톡 · PC 클릭): 가 본 바닥이면 상하좌우로 길을 찾아 그 칸까지 0.13초마다 한 걸음. 누른 칸에 노란 ×
  - 계단을 누르면 거기까지 가서 다음 층, 상점을 누르면 상점까지
  - 몬스터를 누르면 움직이는 몬스터를 따라가 옆에서 공격
  - 멈출 때: 맞았을 때, 새 몬스터가 보일 때, 가는 길에 몬스터가 나타날 때, 다른 키·버튼을 누를 때, 창이 열릴 때. 가 본 적 없는 칸·벽은 무시
- 처음 안내: 마을 말풍선에 "👆 칸을 누르면(클릭하면) 자동으로 걸어가요 · 밀어서 움직이기"와 "🗺 지도 버튼 / Tab: 지나온 길이 화면 위에 겹쳐 보여요", 던전 말풍선에도 같은 내용. 아래 조작 안내 줄(키·터치)에도 추가
- 새 문구 영어·일본어
