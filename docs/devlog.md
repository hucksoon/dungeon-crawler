## 남은 일
- 광고: AdSense 심사 결과 기다리기 → 승인되면 H5 게임 광고(보상형) 신청 → `ads-config.js`를 실제 광고로
- 밸런스 지켜보기: 두 손 무기(왼손 60%) vs 방패 패링, 새 몬스터 20종의 깊은 층 난이도
- 150층 안쪽 밸런스 지켜보기: 150층이 목표가 되면서 파밍할 이유는 생겼어요 (보통 장비는 약 120층 보스에서 막힘). 다만 60~140층 일반 몬스터가 한 방이라 심심할 수 있어요. v4 사용자가 150층까지 얼마나 걸리는지, 지루하다는 말이 나오는지 보고 필요하면 시뮬레이션해 둔 "깊은 층 몬스터 강화 + 10층 구간 성장 + 구간별 상한" 안을 다시 꺼내기
- 로비: 2D 그래픽, 이름 겹침 정리, 오른쪽 "준비 중" 건물에 들어갈 기능 정하기
- 아이디어: 자동 테스트(CI), Xsolla 웹훅 서명 검증
