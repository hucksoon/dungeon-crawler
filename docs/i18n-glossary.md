# 용어집: 한국어 · English · 日本語

게임을 영어·일본어로 옮길 때 쓰는 용어 표예요. 번역은 이 표를 기준으로 하고, 바뀌면 여기부터 고쳐요.
상점(`shop.html`)에서 이미 쓰는 말(캐시, 우편함, 장비 상자, 부활권 등)은 그대로 맞췄어요.

**원칙**
- **네임드 몬스터는 소리대로** (Bulgasari, Gumiho …), 그 칭호는 뜻으로
- **일반 몬스터·보스**는 영어·일본어 게임에서 흔히 쓰는 이름으로
- **아이템·스킬·룬워드·세트**는 뜻으로. 네임드 이름이 들어간 아이템은 그 부분만 소리대로 (Gumiho's Hairpin)
- 일본어는 게임 용어로 흔한 가타카나를 쓰고, 뜻이 중요한 이름(세트·룬워드·유니크)은 한자·일본어로
- 개발 문서(`docs/`, 개발 일기)는 한국어로 둠

### 일본어 관용 이름 (네임드 원칙의 예외 후보)

일본에도 같은 전설·불교 개념이 있어서 일본 플레이어에게 더 익숙한 이름들이에요. 영어는 원칙대로 소리(Gumiho …)로 둬요.

| 한국어 | 소리대로 (지금) | 일본 관용 이름 | 설명 |
|---|---|---|---|
| 구미호 | クミホ | **九尾の狐** | 일본에서도 아주 유명 (玉藻前 전설) |
| 이무기 | イムギ | **蛟竜** (こうりょう) | 아직 하늘에 오르지 못한 용. 이무기와 뜻이 거의 같음 |
| 저승사자 | チョスンサジャ | **死神** | 저승으로 데려가는 사자 |
| 염라대왕 | ヨムラデワン | **閻魔大王** | 매우 유명 |
| 불가사리 | プルガサリ | (없음) | 일본에도 プルガサリ로 알려져 있어서 그대로 |
| 업경대 (유니크) | 業鏡 | **浄玻璃の鏡** | 閻魔大王 앞에서 죄를 비추는 거울. 일본 불교의 같은 물건 |
| 저승 / 명부 | 冥界 / 冥府 | **冥土** / 冥府 | 冥府는 그대로, "저승의 왕"은 冥土の王 후보 |

관용 이름을 쓰면 그 이름이 들어간 아이템도 같이 바뀌어요: 구미호의 비녀 → 九尾の狐のかんざし, 염라의 관복 → 閻魔の官服, 업경 목걸이 → 浄玻璃のネックレス

## 문장 규칙

- **아이템 이름 순서**
  - 한국어 (지금 그대로): `고대 +10 지옥의 얼음 레전더리 투구`
  - 영어 (영어식): `+강화 [Ancient] 등급 [Nightmare|Hell] 종류 [of Flame|of Frost|of Thunder]` → `+10 Ancient Legendary Hell Helm of Frost`, `+3 Rare Nightmare Dagger`, `Epic Bracers`
  - 일본어: 한국어와 같은 순서 → `古代 +10 地獄の氷 レジェンダリー 兜`
- 세트 조각: `고대 +10 지옥의 화염의 투구` → `+10 Ancient Hell Inferno Helm` → `古代 +10 地獄の 業火の兜`
- 룬워드·유니크: `고대 +10 천하무적` → `+10 Ancient Invincible` → `古代 +10 天下無敵`
- 룬 이름은 어느 언어든 한글 그대로: `천하무적 = 차 하 마 자` → `Invincible = 차 하 마 자`
- 숫자·단위: `공격력 +12%` → `Attack +12%` → `攻撃力 +12%`. 층은 `10층` → `Floor 10` → `10階`
- 조사가 붙는 문장(`을(를)`, `이/가`)은 언어마다 문장 전체를 따로 씀 (조각을 이어 붙이지 않음)
- 일본어는 반말 서술(`〜した`)이 아니라 상점처럼 `です・ます`로. 전투 기록만 짧게 (`ゴブリンを倒した。`)
- 영어 버튼·제목은 단어마다 첫 글자를 대문자로 (Claim All, Link Account)
