2026년 11월 10일 (화) · 태그: 개발일기, 업데이트, 이용약관, 상점, 디스코드

이미지 3장은 본문과 함께 복사돼요. 네이버에 이미지가 안 들어가면 아래에서 저장해서 그 자리에 올려 주세요: 1. 이용약관 페이지: 맨 위 한눈에 보기와 한국어·영어·일본어 버튼 · 2. 계정 줄에 생긴 플레이어 ID 버튼 · 3. 내 플레이어 ID 창: ID와 복사 버튼

지난번에 상점에서 장비 상자 대신 스킬 스킨을 팔기 시작했어요. 돈이 오가는 상점이 있으니 "무엇을 사는 건지, 환불은 어떻게 되는지"를 한곳에 정리해 둘 필요가 있었어요. 그래서 이용약관 페이지를 만들었어요.


이런 내용이 들어 있어요

• 캐시와 스킬 스킨은 게임 안에서만 쓰고, 현금으로 바꿀 수 없어요.

• 결제는 Xsolla가 처리하고, 카드 정보는 게임에 오지 않아요.

• 쓰지 않은 캐시는 결제 후 7일 안에 환불을 요청할 수 있어요.

• 사자마자 바로 쓰이는 스킨이나 부활권, 이미 쓴 캐시는 환불이 제한될 수 있어요.

• 버그 악용, 자동 사냥 프로그램, 기록 조작은 금지예요.

• 게임을 끝내야 하면 30일 전에 알리고 남은 캐시 환불 방법을 안내해요.


이용약관 페이지: 맨 위 한눈에 보기와 한국어·영어·일본어 버튼


어디서 볼 수 있나요

페이지는 한국어·영어·일본어로 볼 수 있어요. 오른쪽 위 버튼으로 바꾸거나, 게임에서 고른 언어로 처음부터 열려요. 게임 화면과 상점 맨 아래의 이용약관 링크로 들어갈 수 있어요.


예전 게임 화면 아래에 있던 "장비 상자 확률" 링크는 이제 상자를 팔지 않아서 이용약관 링크로 바꿨어요.


내 플레이어 ID

디스코드에서도 던전 크롤러 상점을 열 준비를 하고 있어요. 디스코드 상점에서 아이템을 사면 플레이어 ID를 넣어서 내 계정으로 받게 돼요. 그런데 지금까지는 게임 어디에도 내 ID가 보이지 않았어요.


그래서 계정을 연결하면 위쪽 계정 줄에 🆔 플레이어 ID 버튼이 생기게 했어요. 누르면 내 ID가 나오고, 복사 버튼으로 바로 복사할 수 있어요.


계정 줄에 생긴 플레이어 ID 버튼


내 플레이어 ID 창: ID와 복사 버튼


이 ID로 로그인할 수는 없지만, 그래도 다른 사람과는 나누지 않는 게 좋아요. 게스트로 하고 있다면 계정을 연결해야 버튼이 보여요.


처음 디스코드에서 ID를 넣어 보니 "확인할 수 없다"는 오류가 났어요. 디스코드 상점이 ID를 물어보는 방식과 게임 서버가 대답하는 방식이 달랐거든요. 디스코드 상점 전용으로 대답하는 곳을 따로 만들어서 고쳤어요.
